About this demo. The model is a multi-task convolutional network with two classification heads, 94k parameters, exported to ONNX and running locally via onnxruntime-web. It was trained on 14,000 synthetic job titles with realistic CRM noise and measures 94.3% seniority accuracy and 93.1% function accuracy on a held-out test set of 3,000 titles. Synthetic training data means real-world accuracy would be lower until retrained on labeled CRM data; the pipeline, not the headline number, is the point.
